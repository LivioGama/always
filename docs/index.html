Why Always?

🎯

Always-On

No push-to-talk, no app to open. The daemon listens 24/7 with intelligent VAD, invoking Whisper only when speech actually happens.

⚡

Lightning Fast

End-to-end latency under 700ms with speculative transcription. Your text appears before you even finish speaking.

🎯

Zero-Config Paste

Pastes wherever your cursor is via Core Graphics keyboard events — works in any macOS app including Xcode and JetBrains.

🧠

Smart Filtering

Three-layer filter pipeline catches garbage like "thanks for watching" and "[Music]" that Whisper occasionally invents.

🎤

Speaker Verification

Teach Always your voice with three quick samples. Dictation responds ONLY to you — movies and others are ignored.

📚

Custom Glossary

Import project-specific vocabulary from macOS Text Replacements, SuperWhisper, and MacWhisper. Auto-corrects mistranscriptions.

Installation

🍎 macOS Recommended

Homebrew tap (coming soon)

brew install --cask LivioGama/tap/always

Or download the signed + notarized DMG from GitHub Releases

🐧 Linux CLI Only

From source

cargo install --git https://github.com/LivioGama/always always --no-default-features --features linux

Keyboard/clipboard features are stubs on Linux

🪟 Windows CLI Only

From source

cargo install --git https://github.com/LivioGama/always always --no-default-features --features windows

Keyboard/clipboard features are stubs on Windows
